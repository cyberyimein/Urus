# 当前日线机会与回放内存修订（2026-09-07）

用户需要首先判断最新完成日线对应的当前状态，不能把历史失效计划误读为当前提醒。

## 展示约定

- 主区标题为“当前日线机会”，显示最新完成收盘日期、参考收盘价和当前突破计划结论。
- 失效或到期计划退出主区。旧区间、失效线、形成日期和失效日期保留在默认折叠的“历史计划与复盘”。
- “准备中”改为“等待突破确认”。无有效突破计划只描述本策略的输出，不代表股票不存在其他机会。
- 财报、重大事件及其覆盖情况不在本轮开发范围内，不再作为缺数据提醒展示；不将未接入解释为已经核实。
- 历史重建、逐根来源信息等技术细节进入追溯区；真实价格证据问题仍可见。

## 请求与内存约定

- 个股页面通过 symbol 参数请求所选标的的回放，避免每次重算整个股票池。
- 相同的并发回放请求共享一次计算，限制重计算并行数。
- 回放子进程自行只读加载数据库与图表，结束后退出以回收其 Python 堆。
- 页面切换与卸载取消待完成请求；同一个冻结数据集的图表在页面内复用，切换数据集时释放引用。
- 策略规则和冻结市场数据不因这次展示及资源管理修订而改变。

## 验证与部署

本地集成验证：backend 全量 pytest 通过，frontend 全量 Vitest（64 tests）通过，frontend production build 通过。新镜像构建尚未执行：本机 Apple Container 操作被 Codex 自动审批以 usage limit 拒绝；当前 macmini 仍运行上一版 memfix 容器，持久化数据和采集配置未改变。
