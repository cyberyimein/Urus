## 本轮交付

- `app.intraday.replay.replay_observations` 验证原 capture hash 与显式观察时间，按实际观察顺序复用 P3 投影和同一 P4/P5 规则核心。每 task 独立状态与单调槽游标，重复和晚到旧修订不覆盖已处理状态。
- 原始观察与重建来源分别计数。同一 task 单次回放混入另一来源时明确跳过，不能借重建候选生成标为原始观察的确认事件。
- 报告保存规则默认值／参数快照及 hash、投影参数、输入身份、事件、跳过原因及紧凑能力摘要；即使零事件，也能解释时间边界未验证或其他输入门槛。
- `app.intraday.outcomes.measure_outcome` 固定测量 15／30／60 分钟后的价格变化及最大向上／向下变化，要求同 session、以开盘网格对齐的连续完整 5 分钟窗口。普通日与半日市不得跨收盘凑数。
- 两条冻结线在同一 bar 触及时保留“顺序未知”；RS 等没有价格方向的标签不推断成多空交易。不输出交易胜率或收益承诺。
- 显式 CLI 从本地 JSON 读取观察记录，只能新建报告文件，拒绝覆盖；不连接主库、sidecar 或 provider，不写实时状态。
