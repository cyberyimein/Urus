## 已审查的关键语义

- 只使用当前 cutoff 以前完整的 5 分钟 bar，按每个标的所需连续窗口判断可用性；坏成员不屏蔽其他健康成员。
- 分钟时间边界未经验证时允许 P3 展示，但不生成正式事件。真实采集链目前仍记录未经验证，不能将离线 fixture 的通过当成真实边界已验证。
- S1 比较 t 与 t−2 的同窗口相对收益，连续两槽确认；S2 使用前置 Wilder ATR 与 2bp 价格缓冲；S3 急跌严格小于 −2 倍前置 ATR，不依赖 RVOL。
- 放量事件必须有合格跨日同时段 RVOL 基线。当前采集投影没有该基线，能力明确不可用；不使用当日均量代替。
- 状态、不可变事件与消费 cursor 同事务写入；两个 watcher 需在数据库互斥下重新读取状态。只扫描 cursor 之后的有界源槽，不为列出晚到旧记录而反复扫描全部历史。
- 采集时间与插入时间分开保存。源路径、task 和 processor 隔离；历史事件的 status 与当前 setup 的 current_status 分开查询。
- 无新 source 时仍可过期，GET 不触发过期写入。收盘边界由交易日历决定，包含提前收市。
- 网页每 15 秒读取有界最新事件，行情仍每 60 秒读取；只给同标的、同交易日的有效 setup 画冻结线。终态不得遗留旧候选线。
