# Urus 买入机会设计 v3：主动查看与条件化决策

状态：用户已授权按本边界实施；2026-09-05。唯一当前规范为本文与[实施清单](strategy-opportunity-engine-implementation-handoff.md)。v1/v2仅作历史：[v2归档](archive/opportunity-engine-v2/strategy-opportunity-engine-improvement-plan.md)。旧审查的交易/推送链要求不再作为产品验收门。

## 1. 产品目标与边界

第一性原则：用户主动打开系统时，能否获得有证据、未过时、值得研究的买入机会，并理解此刻可考虑什么、需要等待什么、什么会使判断失效。

Urus没有信息推送、下单、真实持仓管理功能。查看不等于接受建议，更不等于成交。用户可以不买，也可以自行选择价格与时间。不得假定送达时间、默认15分钟响应、自动保护单、资金账户或用户盈亏。

主链：授权Universe → 冻结证据/全池扫描 → 结构与独立事件 → 查看时点投影 → 条件化价格计划 → 固定截面的机会质量研究。

系统负责发现质量、判断时效、条件清晰度、漏掉机会的解释。未来最高涨幅不能冒充实际获利；触及价格区域不能冒充成交。绝对价格表现、相对筛选优势、条件化研究收益三种证据分别表达。

首期美股股票/普通股票ETF、现金多头研究、1/2/5/10/20交易日视角，沿用当前授权Universe。不要扩大数据订阅/采集、部署、定时任务、外部消息、远端workflow、券商操作。用户已授权本地实现和测试，不要求为了这些可逆工作重复确认。

## 2. 保留与收窄

保留Dataset、Universe/观察组版本、Observation Run、价格证据与修订、确定性策略、现有期权证据、远程AI事实边界。

R00保留失败突破前置阈值、无价格突破不由放量制造方向、确认/失效矛盾降级、两个watch不升级买入、独立风险投影、未知阶段年龄、proxy标识、完整规则版本/hash。均值回归新交易公式仍不属于本包。

保留外部agent已修正的证据、生命周期、执行研究、统计与账本代码；避免破坏旧实验可重放性。Q0/Q1、M1/D1、用户延迟、仓位/现金/退出账本仅作显式选择的legacy研究情景，主产品与v3主研究入口不依赖它们，不继续为上线而补模拟券商。

移出必做项：推送/送达/响应记录、45分钟提醒TTL、15:45提醒截止、默认15分钟下单、3条待处理提醒、持仓禁入、自动止损、账户净值。这些既不是现有功能，也不是机会质量的主成功指标。

## 3. 证据和知识时间

所有判断带viewed_at、knowledge_at、market_as_of、source_mode、data_source、source/revision引用、quality、price_basis、rules_hash。observed_pit、historical_reconstruction及synthetic不能互相升级。没有实际可用时间不可标observed_pit；没有当前数据不可将历史缓存伪装live。

可见性按事实类型：完整价格bar的结束与available_at均不晚于knowledge_at；scheduled财报允许事件日期未来但发布/接收时间已可见；actual只允许发布后可见。迟到公告在当前知识时间重评，旧bar不回退行情游标，知识变化不创造价格穿越。截止时取当时可见revision，旧实验不可改写。

同一次计算使用一致价格口径；原始quote与复权结构需冻结映射才能比较。quote验证symbol；拆股/分红/停牌/退市和缺数据不能产生伪收益。有限正价格、合法OHLC、带时区时间严格校验。真实覆盖不足须显式报告，不为了fixture通过放宽契约。

## 4. 全池扫描和S1

每个授权symbol每次扫描都有记录，包括disabled、资产不适用、coverage_miss、规则拒绝。基础资格：61根完整日线、close>=5、20日中位原始成交额>=2000万美元。proxy成交额明确标识，不将复权close×原始量冒称真实原始成交额。

固定结构以完整交易日D为截止：

```text
A = 最近14个TR的简单平均
L = D及此前共20根日bar最高价
S = D及此前共5根日bar最低价 - 0.25*A
U = L + 0.50*A
A > 0 且 0.5 <= (L-S)/A <= 3
```

冻结L/S/A/U及锚/base、价格口径。准备期从下一真实session起最多5个session，最后session边界bar先处理再到期。日级为初始可用能力；已授权且完整的15分钟数据可独立评价，不强制新建采集。

事件规则：previous completed close<=L、current completed close>L；opening gap仅常规开盘bar，late_discovery/cross_unobserved与fresh分开。low<=S先失效，>U仍记录穿越但显示延伸。持续在L上方不反复制造机会。

setup、trigger、view_snapshot、outcome标签独立。setup首次穿越后resolved，但resolved表示结构不再等待首次触发，不等于历史机会不可查看。当前计划有效性必须按后续可见价格/事件单独重评。旧20日标签pending不锁住新结构。前结构关闭后3个新完整session和新锚/base允许重建，价格与新L比较。身份不含查看时间、组ID或每日扫描日；知识评估可有独立snapshot身份。

## 5. 查看时点投影：R03的新核心

新增纯函数与严格契约，输入冻结setup/可选trigger、截至knowledge_at的价格/事件/质量证据、viewed_at；输出只读机会投影。查看不改变经济事件，不调用执行研究或未来标签。

必须字段：symbol、setup/trigger/scan关联、版本、viewed_at/knowledge_at/market_as_of、basis/source/data_source、quality/freshness、status、L/S/A/U、reference_price/reference_kind、distance_to_trigger_atr、条件/失效说明、event_risk、research_support、reason_codes、证据引用、内容hash。当前基础无研究资格时research_support=unknown，不能凭策略评分自动升级。

状态由可验证事实决定，优先处理缺数据/过时/失效，避免旧有效状态残留：

| 状态 | 意义 |
|---|---|
| unavailable | 无足够证据判断 |
| stale | 当前判断所需证据过时；可以展示旧结构及as-of，不宣称当前成立 |
| invalidated | 可靠可见路径已触及S或结构失效；之后反弹不复活同一结构 |
| expired | 准备结构等待期结束而未触发；不是提醒TTL |
| preparing | 尚未观察到突破，等待预定条件 |
| triggered_unverified | 穿越事实存在但新鲜度/连续覆盖不足，或只够研究判断 |
| in_entry_zone | 新鲜、同口径且结构/事件已核查，价格在[L,U]；仅“位于预设研究区间”，不是下单指令或已验证盈利 |
| extended | 当前参考价>U，不能追认旧价仍可参与 |
| waiting | 已触发后回到L下但未失效，等待重新验证；首版不得事后当作已验证回踩策略 |

日线模式明确reference_kind=daily_close；无当前quote仍可显示日线准备/触发/延伸，但不能显示in_entry_zone来冒充实时参与资格。每个状态附数据粒度和时效。盘中quote默认最大年龄60秒；历史bar不能靠刷新viewed_at变新鲜。daily新鲜度按完整交易session与冻结日历验证；日历/覆盖不够时保守标受限。非交易时段不因自然日差简单断言有效。

若首次突破bar已越U，此后回落至区间，首版仅waiting/triggered_unverified，不将已错过事件改写成新买点。未来回踩条件另做版本。历史最低价不明发生顺序时不确定，不能擅自判定保护止损成交。

财报未来2session内使当前参与条件受限，持有期20session内事件单列风险，不把全部事件硬挡；ETF公司财报不适用。无事件覆盖仍可展示结构，不能显示已完成全部风险核查。同symbol已有持仓不是系统已知事实，不设默认禁入。

## 6. 排序和信息成本

同symbol跨组去重但保留组归属；机会与风险独立。首版只提供可解释的研究浏览顺序：状态分层，准备项按distance_to_trigger_atr升序，同层确定性symbol打平；当前区间候选无可靠优势证据时并列。禁止将距离近描述成预期收益最高。

分页/用户筛选只影响展示，不删除全池研究记录。不设置3条提醒上限，不按展示次序假设资金分配。没有合格机会允许空结果。

## 7. R04主研究：固定查看截面，而非虚构交易

新增独立v3入口，输入原始冻结证据、全池成员/版本、session日历、预注册观察截面、开发/锁定日期、价格口径和规则身份。输出scan→setup/trigger→view snapshot→独立标签→assessment。不得要求输入预计算P&L、送达时间、响应、资金或仓位。

默认可用模式daily：在完整日bar实际可知后形成查看截面；参考价是该已完成close，收益必须称reference_price_return/价格路径代理，不称可成交回报。盘中固定10:00 ET仅在当时完整可见数据可用时运行；不能由日线合成盘中覆盖。5/15/30分钟是机会持续性观察偏移，不是用户响应或成交假设；没有相应数据，曲线unavailable。

标签以snapshot参考时点为锚：1/2/5/10/20真实交易session的固定终点价格变化、相同起终点benchmark超额、MFE/MAE（只含参考时刻之后路径）、结构失效、区间首次可观察触及、区间持续可观察覆盖。触及不等于成交；bar同时触发相反条件且顺序不明为ambiguous。下一日/之后价格不得参与snapshot形成或排序。

缺未来数据：尚未到期pending、已到期但缺失censored、路径不明ambiguous，全部保留。标签用evaluation_as_of判断成熟，不能把任意最后bar日期当今天。缺benchmark→相关比较unknown；不得填0。路径缺口不因后续有第N根bar就假装连续。公司行动口径未知则受限。

两种统计单位单列：每次固定查看截面回答“用户此刻打开会看到什么”；按经济机会ID去重回答“发现多少独立机会”。重复查看不能增加独立事件样本数。开发/锁定、source_mode/data_source、daily/intraday、variant分别分组，主cohort在manifest冻结。拒绝样本用同截面固定期限标签比较，只在覆盖可比范围报告，不宣称全市场召回率。

主评价状态集合也须预注册：初版为triggered_unverified/in_entry_zone（daily实际只能前者），且必须存在结构身份；preparing/waiting/extended/stale/unavailable分别描述，不混作触发后仍值得查看的主候选表现。标签携带snapshot_status，完整池的拒绝诊断不进入主候选均值。此集合是可审计研究定义，不把unverified自动变成已验证买点。

核心指标：覆盖/拒绝原因、候选数量、固定期限收益分布/中位数/均值、超额分布、MFE/MAE、结构失效率、过时/已延伸比例、条件区间出现/持续性、盈利贡献集中与规则漏掉的盈利。过滤器分别报告去掉亏损、漏掉盈利、候选频率和同口径价格结果差异；不要从净和负部反推减少亏损。

无证据不输出胜率预测、最优排名或“有盈利支持”。主评价输出机会质量证据和局限，初始support=unknown/research_only。要升级需另行预注册主假设及独立评价；样本数不是自动认证。统计沿用跨symbol同步交易日块bootstrap（20session主、10/40敏感性、5000次、固定seed）；不足有效块只给点估计与unknown，不因同一事件重复快照缩窄区间。

可选小情景：预先冻结一种入场条件与固定终点、成本代理，评估条件化价格净变化；必须用可知条件和其后价格，不能事后挑最低价。已有Q1/M1/D1/portfolio引擎保留独立旧入口，不依赖这些结果才能显示研究机会。模拟/用户收益均不得混入主价格标签。

## 8. R05主动查看接入

R00–R04相关v3改动及验收通过后接入现有Dataset读取接口与个股工作区，必要时观察组复用同投影。优先只读派生投影，不新增账户、推送表、entry_intent表或通用任务平台。

最小接口：按现有dataset_id读取机会投影，明确它是该冻结数据集截至当时的判断；以实际查看时间评估时效。读取不得触发行情补采或写历史Dataset。后端主链不import研究outcome模块。缺数据有结构化受限返回，未知dataset沿用404。不得接受未来knowledge_at伪造当前视图。

前端小范围呈现价格区间、状态、as-of/来源/质量、条件与失效、unknown研究支持；不重做UI，不写买入/发送/已成交控件。日线模式标题明确“日线研究计划”，旧收盘参考不显示“当前可买”。现有AI和期权展示保留事实边界。既有页面/接口回归通过。

## 9. R06验证、R07条件增强

R06改为主动查看回放与现有数据覆盖验证：不同查看时间、旧Dataset、缺quote、盘中/日线、跨session、重复打开、未来数据隔离。无需推送shadow、真实用户操作或新订阅。交付可重复fixture、可用现有数据覆盖清单（没有来源则明确未评估）、真实/构造结果分列、报告工程完成与收益证据不足的差别。

R07仍是有证据才能增加一个增强（回踩/相对强弱排序/量能/事件/期权背景/AI解释）。本轮不因清单存在而自动扩张策略；没有独立增益证据交付“暂不增加”及下一实验假设即可，不需要等待用户回复才能完成当前授权开发。

## 10. 版本与验收

原版v2执行研究与结果可读；v3独立schema/政策/manifest。新实验hash包含全输入、scans/diagnostics、日历、参数/规则及seed；同run不同内容拒绝，不覆盖旧实验。历史报告保留并加scope superseded说明，不伪装外部agent未修复。

新验收使用V编号，避免重解释历史B测试；旧B中时间/来源/幂等/基础策略回归仍应通过，交易专用测试只验证可选研究模块，不再代表产品验收。

| ID | 必须行为 |
|---|---|
| V01 | 无送达/响应/仓位/订单字段，也能完整生成主研究和查看投影 |
| V02 | 没有quote只有日线，显示日线as-of和受限状态，不报实时可参与 |
| V03 | 打开旧Dataset不会把market_as_of或证据年龄重置为当前 |
| V04 | 价格>U、已触及S、准备过期、事件未知分别有正确状态/原因 |
| V05 | 同结构重复查看/跨组只有同一经济机会，标签pending不挡新结构 |
| V06 | 未来bar/quote/actual公告不可见；迟到新知识只改当前评估 |
| V07 | 未来区间触及只是观察事实，不伪造成交或用户盈亏 |
| V08 | 同根bar路径不明为ambiguous，MFE/MAE不含参考前路径 |
| V09 | 开发/锁定、粒度、来源、variant及查看偏移严格分离 |
| V10 | 缺benchmark/未来数据/corporate-action映射不补0或删亏损 |
| V11 | 全池拒绝、缺数据、筛选造成漏掉盈利分别记录 |
